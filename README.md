# AMT — Industrial Inspection

Статический лендинг на чистом HTML/CSS/JS.

## Структура

- `index.html` — страница
- `styles.css` — стили и адаптив
- `script.js` — небольшие scroll/menu-анимации
- `assets/amt-drone.png` — рендер дрона
- `assets/fire-detection.jpg` — пример визуального обнаружения

## GitHub Pages

1. Создайте новый репозиторий.
2. Загрузите все файлы из этой папки.
3. В GitHub откройте **Settings → Pages**.
4. В качестве source выберите ветку `main` и папку `/root`.
5. Сохраните — GitHub Pages выдаст адрес сайта.

Почту `hello@amt.example` в `index.html` замените на реальный адрес.
